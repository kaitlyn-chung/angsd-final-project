# angsd-final-project
Scripts used to generate data from start to finish for my analysis of next-generation sequencing data final project. 
This repository contains scripts for a start-to-finish pipeline from downloading fastq files from GEO to generating read counts in R with the goal of replicating generated in the paper "A window-of-opportunity trial reveals mechanisms of response and resistance to navtemadlin in patients with recurrent glioblastoma" (https://www.science.org/doi/10.1126/scitranslmed.adn6274).
